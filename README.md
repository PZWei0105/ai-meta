# 版本答案 META：AI 工具雷達

痞子葳（PZ）的 AI 工具雷達。把四家 AI（Claude、ChatGPT、Gemini、Grok）和本機模型當成一款一直在改版的遊戲：每小時讀一次官方更新紀錄、價格表、狀態頁與 Hugging Face，回答三個問題：**這週改了什麼、我的方案值不值、我的筆電跑不跑得動**。

- **版本**：本週改版號（例如 26.43＝2026 年第 43 週）、加強／削弱／新增／移除的數量、四家伺服器狀態、跟你有關的改版、即將發生的漲價與停用倒數、你的版本答案、訂閱總帳。
- **改版**：全部改版公告（翻成繁體中文），可以只看跟你有關的、看加強削弱、依廠商篩選。每一則都有分類理由與官方原文連結。
- **商城**：你的每月訂閱帳單與判定（維持、可升、可降、用途重疊）、四家方案比較、API 價格表（附漲價日期）、API 試算。
- **本機**：精選開源模型在 RTX 5090 Laptop GPU（24 GB）上跑不跑得動、吃多少顯示記憶體、每秒幾個 token；可以拉對話長度、換壓縮等級即時重算。另有生圖、生影片模型、Hugging Face 新上架雷達、要裝的工具最新版。
- **攻略**：八件事（寫程式、小說、腳本、查資料、翻譯、生圖、生影片、即時話題）各用什麼，附理由；有相關改版時亮黃燈提醒複查。還有額度守則、額度用完的接力順序、本機路線圖、商用授權守則。

## 規則

- 改版分類、「跟你有關」分數、訂閱判定、跑不跑得動，全部是固定規則（`config/` 和 `pipeline/`），同樣的資料永遠得到同樣的結果，而且一定附理由。
- 價格、狀態、檔案大小每輪自動讀官方資料；訂閱方案表與攻略是人工整理（附官方來源），官方方案頁一變動，App 會標「方案頁有變，待核對」，攻略則會依相關改版亮燈。
- 翻譯用 GitHub Actions 裡的本機小模型（Qwen3 8B），不用任何金鑰、不花 Claude 額度。

## 更新

- GitHub Actions 每小時第 13 分自動跑（`.github/workflows/meta.yml`）。
- App 右上角「更新」：沒有遙控鑰匙時重新讀最新資料；有遙控鑰匙（只能控制這個 repo 的 fine-grained token，Actions 讀寫）時會直接叫 GitHub 重抓一輪。
- 你的方案、用途、撞額度頻率、實付金額只存在手機（瀏覽器本機儲存），可以在「我的設定」備份。

## 不需要金鑰、不花錢

全部用公開資料：四家官方更新紀錄、說明中心、價格頁與狀態頁、OpenRouter 模型表（交叉核對價格）、Hugging Face 公開 API、GitHub Releases、App Store 公開查詢、每日匯率。不收業配、沒有導購連結。
